Normal Texture Details - rre36/lab-pbr GitHub Wiki

The Normalmap will not just contain the normals, but also ambient occlusion and a heightmap

  • Material ao:

    • ambient occlusion gets stored in the blue channel of the normalmap
      • the z-component of the normalmap can be calculated using this method sqrt(1.0 - dot(normal.xy, normal.xy))
    • this attribute is stored linearly, 0 meaning max AO and 255 meaning no AO

  • Heightmap:

    • the heightmap used for POM is stored in the alpha channel of the normalmap, a value of 0 (pure black on the heightmap) represents a depth of 25% in the block.
    • however be aware that a value of 0 on the heightmap will cause some issues with certain shader's POM-implementations, so a minimum of 1 is recommended instead

Reasoning for this specific organization:

For the AO in blue, it's because in a normal map the 3 components of a pixel represent a vector of length 1. Since we know the length, we only need 2 of the 3 components to to reconstruct the vector (thanks Pythagore), this mean that there is one free channel in the normal map texture, it could have been red or green, but blue was chosen, and AO put in here.
