Create a New Project - Null-MC/PixelGraph GitHub Wiki

Certain options must be configured before managing resource pack content; to simplify this a "New Project" wizard has been added to the user interface, which will guide you through the process. However projects can still be setup manually.

Using the User Interface

Start by clicking one of the "New Project" buttons. This will launch the New Project wizard.

First select the directory where all of your resource pack content will be stored. This should be an empty folder if it exists; if you have an existing resource pack, you can choose to import it in later steps. You can also choose to have an empty directory structures created for you.

Before any content can be added, you must first choose an encoding for storing your resource pack content. The default and recommended value is raw, which will allow you to manage each encoding channel in a separate texture.

The final step, a few options can be specified.

  • Create Default Profile - When enabled, a basic [Pack Profile](Pack Profile Properties) will be created for publishing named 'default' and using Lab-1.3 format.
  • Import Existing Content - Allows the content of an existing Resource Pack to be imported into the current project. You can select either a local directory, or a compressed Zip archive.

After clicking Create, your project will be setup.

If you chose to import an existing resource pack, you will be prompted to select the directory/archive you would like to import. See Import-an-Existing-Resource-Pack for more information.

Manual / Command-Line Usage

You can also create projects without using the UI. Open the directory where you plan to manage your content and add a Pack Input file named input.yml. This file defines how PixelGraph will import and modify source content, and must be configured before doing so.
