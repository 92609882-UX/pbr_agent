Material Formats - Null-MC/PixelGraph GitHub Wiki

PixelGraph allows you to define any custom input or output encoding for materials, but a few common formats have been included to simplify usage. See the PBR Channel Encoding page for more details.

  • Lab-1.3 - The latest standard for PBR materials in Minecraft.
  • Lab-1.2 - For support only.
  • Lab-1.1 - For support only.
  • legacy - Also known as "OldPbr", most notably still in-use by SEUS shaders.
  • specular - Also known as "grayscale specular", is a legacy specular format preceding PBR.
  • diffuse - Non-PBR support for standard diffuse-only resource packs.
