# 附魔灌注台 v6 红毯织物优化

本版本只优化普通版和进阶版**顶面**红毯区域，保留原始颜色、金框、紫色核心、底面和侧面设计。

**v6.1 修复（侧红毯恢复）**：v3→v5 期间侧贴图的红毯曾被误判为"不应存在"而改为底座深色（基础颜色贴图同步重映射），导致侧面丢失红毯。经复核官方模型 UV（side 采样 `[0,4,16,16]`，中部红毯完全有效）后，已用 `work/scripts/fix_v6_side_carpet.py` 从官方 16×16 重建侧贴图：128px 原图保留官方红毯（占比 14.8%），`_n`/`_s` 按 v3 材质平台规则重新生成（红毯 = red 材质，光泽 28，无发光）。

改动包括：

- 交错经纬纤维微法线；
- 轻微绒面起伏和布料边缘细节；
- 布料低光泽度；
- 织物孔隙率调整到羊毛/布料范围；
- 保留原有红毯的 POM 大结构，不让纤维细节产生夸张视差；
- 不改变红毯区域的自发光通道。

使用时关闭旧版附魔灌注台 PBR，只启用 `EnchantingInfuser-PBR-128x-v6.zip`。近距离观察并开启支持 LabPBR 的光影、POM 和适度 Bloom；布料微法线在斜视和近距离高光下最明显。

生成脚本：`work/scripts/enhance_enchanting_fabric_v6.py`（顶面红毯增强）、`work/scripts/fix_v6_side_carpet.py`（侧红毯恢复）。
