# 附魔灌注台 v7 紫水晶立体化

在 v6（红毯织物优化）基础上，只优化**高级附魔台侧面紫水晶簇**，不改动其他任何区域。

## 改动内容

### 1. 晶体簇立体高度（`_n` A 通道）

| 层级 | 高度 | 说明 |
|---|---|---|
| 晶尖 | 1.00 (255) | 主簇双峰顶 |
| 晶柱 | 0.90 | 晶体主干 |
| 柱间沟 | 0.55 | 晶柱之间的窄缝（视觉分割晶体） |
| 收坡 | 0.50 | 外缘过渡 |
| 底座 | 0.44 (112) | 黑曜石底 |

晶体簇布局：右侧主簇（x9-13, y11-15 栅格）+ 左侧小簇（x3-4）。

### 2. 边界连接优化（核心）

- 晶体高度平台用 `GaussianBlur(2.2)` 软过渡（70% 模糊 + 30% 原值），**消除 v6 的断崖突变**（v6 曾在 8px 内从 225 → 31 跳变）
- 晶簇外扩 1 格带向底座收拢（35% 原值 + 65% 底座），形成 8px 宽渐变坡
- 实测平滑度：y 向平均高度差 **5.96 → 5.16**（改善 14%）
- 剖面验证：`213 232 236 245 244 231 223 160 132 116 112`（峰→坡→底座无缝）

### 3. 晶体材质（`_s`）

| 通道 | v6（混杂） | v7 |
|---|---|---|
| R 光滑度 | 55~235 乱 | **200**（高光泽晶体） |
| B SSS | 0~145 乱 | **120**（半透光） |
| A 自发光 | 24~255 乱 | **40~70**（仅晶尖微光 70） |

### 4. 法线与 AO

- 晶体区法线按新高度 4 向差分重算，晶面朝向清晰（std 32/28）
- 柱间沟 AO 加深（晶体根部阴影）
- bbox 边缘法线中性（128.5/123.1），无拉扯

## 生成脚本

- `work/scripts/fix_v7_amethyst.py` —— 紫水晶立体化（基于 v6 解包 → v7 解包 + zip）

## 使用

1. 游戏内只启用 `EnchantingInfuser-PBR-128x-v7.zip`（关闭 v5/v6）
2. 近距离看**高级附魔台侧面下部**：紫水晶簇应有晶体凸起、晶柱分割、边缘渐变坡
3. 验证边界：从斜角看晶体与底座连接处**无撕裂/断层**
