# PBR 制作注意事项与 Agent 约束

> 本文是**硬性约束清单**，供人 / Agent 在 `G:\PBR` 三个材质包项目中执行，优先级等同权威规范。
> 依据：`正式版\Agent约束-Designer制作流程.md`（节点流程）、`正式版\Agent约束-LabPBR通道备忘.md`（通道语义）、
> `正式版\PBR材质包制作经验与流程规范.md`（工程参数）。本文补充的是**实战踩坑**。

## 一、开工前必做（否则一定返工）

1. **先读模型，再动贴图**。任何方块先查 `assets/<mod>/models/block/*.json` 与 `blockstates/*.json`，确认：
   - 哪些面引用哪张贴图、每个面的 UV 范围；
   - 是否由**方块实体渲染器**绘制——例如 ProjectE 的炼金术箱子走 `moze_intel/projecte/rendering/ChestRenderer` + `ModelLayers.CHEST`，
     这种情况 UV 来自渲染器**硬编码**（`texOffs(0,19)` 箱体 14×10×14、`texOffs(0,0)` 盖子 14×5×14、锁扣 2×4×1），
     **不是**模型 json 里的 UV；`models/block/alchemical_chest.json` 里只有 `particle` 就是这个信号。
2. **非 16×16 的贴图必须当"多面拼图"处理**（`Agent约束-Designer制作流程.md` 明确要求）：
   按模型 UV 裁切成**多张独立的 128×128**逐张处理，**不要整张 512×512 一起做**。
3. **判材质必须看颜色**。饱和度 / 色相决定材质语义：
   青绿高饱和 = 能量纹路 / 宝石；纯灰 = 金属面板；亮灰 = 亮金属件。
   **只看灰度会把不同材质混为一谈**（本项目实测：箱子 18 个面里 17 面纯灰、只有盖子顶面是青绿纹路）。

## 二、高度（POM 视差）设计规则

4. **以「同颜色的连通色块」为单位分层，块内保持平整**。像素画的高度来自色块分区，不是逐像素亮度。
5. **不要把亮度梯度直接当高度**。原贴图的明暗含"受光/背光"的绘画信息，不等于几何高度。
6. **层级要拉开，但必须符合同类方块的规律**。参考同项目已验收的方块（转化桌侧/顶面 = 跨度 55、6 层均衡）；
   实测全包绝大多数方块在 **45~60 跨度**，**超过 100 即异常**（必然 POM 撕裂，如 condenser 的 127）。
7. **可见外轮廓必须满高（A=255）**，否则 POM 会把邻面迭代进来，方块边缘参差、漏色。
8. **不做交界柔化**（本项目约定：色块之间保持硬边），只允许 8px 宽法线做过渡。

## 三、法线与 AO

9. **法线 Y 方向用 DirectX (Y-down)**：`ny = -(下−上)`，写入 G 时再取 `-ny`。
10. 法线由**平滑后的高度**差分生成，强度按分辨率校准（512px 下约 8~9.5）。
11. **AO 判据必须用「邻域高度 − 当前高度」**，不要用「邻域亮度 − 当前高度」——
    后者对暗色贴图恒为负，AO 会全 255 失效（本项目暗物质块 / 炸药 / 收集器共 7 张踩过）。

## 四、验证方法（必做，禁止凭感觉）

12. **看高度图**：导出 `_n` 的 A 通道当灰度图直接看，应能一眼看出色块分层。
13. **做光照预览**：用 `_n` 的 AO+法线渲染 Lambert 预览（脚本 `work\designer\preview_relief.py`），确认立体感。
14. **四项核心指标**：

    | 指标 | 含义 | 参照 |
    |---|---|---|
    | 高度跨度 | max − min | 同类方块 45~60 |
    | 块级台阶 | 相邻 8×8 块高度差均值 | 转化桌 12.3 |
    | 层占比 | 各层像素占比 | 均衡，不能一层吃掉 90% |
    | 覆盖率 | UV 面覆盖 | **100%**，不能漏面 |

15. **「像素级梯度均值」不是有效指标**——贴图放大 8 倍后块内是纯色，梯度天然接近 0，看它会得出完全错误的结论。

## 五、禁止事项

16. ❌ 用直方图均衡、对比拉伸等数学手段"拉"高度——会破坏原贴图的色块格局。
17. ❌ 在他人的成品上"缝缝补补"——先确认基准版本，再按规范重做。
18. ❌ 手工列举 UV 区域——必须**脚本化**从模型 json 自动提取全部面（漏一个是 100% 会发生的事）。
19. ❌ 未确认基准版本就动手（本项目同时存在 v4~v7，正式版只有一个）。
20. ❌ 声称"完成"却没有量化验证。

## 六、交付检查

21. 改完必须：**重新打包 zip → 验证条目数 → `git commit`（工作区干净）**。
22. 版本管理：**正式版只留最新**，旧版全部移入 `历史版本\`。
23. 修订记录写入 `ProjectE-PBR\说明\` 对应版本说明，并在 `README-目录说明.md` 版本沿革补一行。

## 七、炼金术箱子实战复盘（2026-09-10）

| # | 踩的坑 | 正确做法 |
|---|---|---|
| 1 | 拿 128×128 当基准，实际源图 512×512，UV 全错 | 先量尺寸：`Image.open(p).size` |
| 2 | 手工列 6 个 UV 区域，漏了盖子底面（196 像素） | 脚本解析 `base_chest.json` 的 **18 个面** |
| 3 | 只看灰度，把青绿能量纹路当成"明暗装饰纹理" | **看饱和度/色相**：`sat > 0.35` 判彩色 |
| 4 | 把面板当无纹理平板 → 整体发平 | 面板按色块给多层级（170/190/203/212/236） |
| 5 | 一路加深到跨度 147（异常值） | 回到同类方块的 **85 跨度 / 6 层** |
| 6 | 用 `ny` 正向写 G 通道，法线方向反了 | 用 `-nyo`（DirectX Y-down） |
| 7 | 拿 condenser（跨度 127）当标杆 | 拿**转化桌**（跨度 55）当标杆 |

**最终配方**（`work\designer\v7_chest_blocks.py`）：
源图按 8×8 归回 64×64 块图 → 每个块按颜色归入层级（跨度 85、6 层）→ **最近邻**放大回 512×512 保持块状 → 边缘满高 → 法线（`-nyo`, 强度 9.5）+ AO（邻域高差）。
