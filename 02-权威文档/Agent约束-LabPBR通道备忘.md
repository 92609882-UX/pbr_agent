# Iris / LabPBR 贴图通道备忘

本文按 Iris 支持的 LabPBR 1.3 规则整理 Minecraft 资源包中 `_n` 与 `_s` 贴图的 RGBA 通道含义、取值逻辑和常用制作值。

- 同一方块/物品贴图通常使用同名文件：`xxx.png`、`xxx_n.png`、`xxx_s.png`。
- `_n` 是法线/高度/AO 贴图，负责表面凹凸、遮蔽和视差高度。
- `_s` 是高光/材质属性贴图，负责粗糙度、反射率、金属、孔隙、次表面散射和自发光。
- LabPBR 通道大多使用 8-bit 值，即 `0-255`。下表中的“常用值”可直接作为绘制或脚本生成贴图时的参考。

> 注意：不同 shader 对部分高级通道的表现会有差异，尤其是 POM/高度、孔隙率、SSS 和金属预设。制作时以 LabPBR 规则为基础，再按目标 shader 实测微调。

## `_n` 贴图：Normal / AO / Height

`_n` 贴图的 RGBA 含义如下：

| 通道 | 名称 | 逻辑 | 常用值 |
| --- | --- | --- | --- |
| R | 法线 X | 切线空间法线的 X 方向。`128` 约等于无左右偏移；小于 `128` 向左，大于 `128` 向右。 | 平面 `128`；轻微凹凸通常在 `96-160`；强凹凸可到 `64-192`，避免大面积极端值。 |
| G | 法线 Y | 切线空间法线的 Y 方向。LabPBR 使用 DirectX 风格法线，`128` 约等于无上下偏移。 | 平面 `128`；轻微凹凸通常在 `96-160`；如果法线方向反了，通常需要反转 G 通道。 |
| B | AO / 环境遮蔽 | 材质 AO。`255` 表示无遮挡，`0` 表示完全遮蔽。用于缝隙、孔洞、接触边缘的局部压暗。 | 无 AO `255`；轻微缝隙 `200-240`；明显缝隙 `120-200`；很深遮蔽 `40-120`。 |
| A | Height / 高度 | 高度/视差深度。`255` 表示没有深度或最高表面，值越小越向内凹；`0` 通常视作最大深度，不推荐直接大面积使用。 | 无高度 `255`；轻微刻痕 `200-245`；砖缝/木纹 `120-220`；深槽 `32-128`；最低点建议用 `1` 而不是 `0`。 |

### `_n` 常用组合

| 场景 | R | G | B | A | 说明 |
| --- | ---: | ---: | ---: | ---: | --- |
| 完全平面，无 AO，无高度 | `128` | `128` | `255` | `255` | 最安全的默认 `_n`。 |
| 只有法线，无 AO/高度 | 法线图 R | 法线图 G | `255` | `255` | 从工具生成 normal map 后，把 B/A 改成 LabPBR 语义。 |
| 有缝隙 AO，无高度 | `128` | `128` | `120-220` | `255` | 适合砖缝、块间边缘、雕刻线。 |
| 有轻微视差高度 | 法线图 R | 法线图 G | `220-255` | `180-245` | 适合木纹、石纹、矿石纹理。 |
| 深凹槽/砖缝 | 法线图 R | 法线图 G | `80-180` | `32-160` | AO 与高度一起压低，避免全部黑死。 |

## `_s` 贴图：Specular / Material

`_s` 贴图的 RGBA 含义如下：

| 通道 | 名称 | 逻辑 | 常用值 |
| --- | --- | --- | --- |
| R | Smoothness / 光滑度 | 感知光滑度。`0` 最粗糙，`255` 最光滑；大致可理解为 roughness 的反向控制。 | 粗糙泥土/砂岩 `0-30`；普通石头/木头 `20-80`；抛光石材 `100-180`；湿表面/玻璃/冰 `200-255`；金属常用 `160-240`。 |
| G | F0 / 金属 | 非金属时表示正入射反射率 F0，通常使用 `0-229`；金属时使用 LabPBR 金属预设值或 `255` 泛用金属。 | 普通非金属约 `8-15`，常用 `10`；水约 `5`；玻璃约 `10`；金属预设见下表。 |
| B | Porosity / SSS | `0-64` 表示孔隙率，值越大越容易表现为吸水/潮湿；`65-255` 表示次表面散射 SSS，值越大散射越强。两种逻辑不能同时表达。 | 无孔隙/无 SSS `0`；木头约 `12`；羊毛约 `38`；沙子约 `64`；树叶/蜡/皮肤类 SSS 可从 `80-180` 起调。 |
| A | Emission / 自发光 | 自发光强度。`0` 表示不发光，`254` 接近满强度；`255` 通常表示忽略/无自发光。发光颜色主要来自原始颜色贴图。 | 不发光 `0`；弱发光 `20-80`；中等发光 `80-180`；强发光 `180-254`；兼容默认可用 `255` 表示忽略。 |

### `_s` G 通道：非金属 F0 常用值

| 材质 | 建议 G 值 | 说明 |
| --- | ---: | --- |
| 大多数非金属默认 | `10` | 约等于 4% F0，是最常用的安全值。 |
| 水 | `5` | 约等于 2% F0。 |
| 普通石头、泥土、木头 | `8-12` | 不要为了“看得见反光”把 F0 拉太高，优先调 R 光滑度。 |
| 玻璃、冰 | `10-20` | 主要靠高 R 光滑度表现清晰反射。 |
| 宝石/特殊晶体 | `20-80` | 仅特殊材质使用，数值过高会像金属或塑料。 |

### `_s` G 通道：LabPBR 金属预设

| G 值 | 金属类型 |
| ---: | --- |
| `230` | Iron / 铁 |
| `231` | Gold / 金 |
| `232` | Aluminum / 铝 |
| `233` | Chrome / 铬 |
| `234` | Copper / 铜 |
| `235` | Lead / 铅 |
| `236` | Platinum / 铂 |
| `237` | Silver / 银 |
| `255` | 泛用金属，通常使用原始颜色贴图给金属反射着色 |

| 材质 | R 光滑度 | G F0/金属 | B 孔隙/SSS | A 自发光 | 说明 |
| --- | ---: | ---: | ---: | ---: | --- |
| 普通泥土/石头 | `10-50` | `10` | `0-8` | `0` | 粗糙非金属。 |
| 木头 | `30-80` | `10` | `12` | `0` | 木纹可局部提高 R。 |
| 羊毛/布料 | `0-25` | `8-12` | `38` | `0` | 低光滑度，高孔隙。 |
| 沙子/砂岩 | `0-30` | `8-12` | `64` | `0` | LabPBR 孔隙率上限的典型材料。 |
| 抛光石材 | `100-170` | `10-15` | `0` | `0` | 不要把 G 误调成金属。 |
| 玻璃/冰 | `220-255` | `10-20` | `0` | `0` | 高光滑度，低到中等 F0。 |
| 铁块 | `170-230` | `230` | `0` | `0` | 金属材质，G 使用铁预设。 |
| 金块 | `180-240` | `231` | `0` | `0` | 金属材质，G 使用金预设。 |
| 铜块 | `160-230` | `234` | `0` | `0` | 氧化区域可降低 R。 |
| 红石灯/发光纹理 | 视材质而定 | 通常 `10` | `0` | `80-254` | A 控制发光强度，颜色来自原始贴图。 |
| 树叶/植物半透材质 | `10-60` | `8-12` | `80-160` | `0` | B 进入 SSS 区间，用于透光感。 |

## 制作检查清单

- `_n` 平面默认值使用 `RGBA(128, 128, 255, 255)`。
- `_s` 普通非金属默认可从 `RGBA(30, 10, 0, 0)` 起步，再按材质调 R/B/A。
- 金属不要只提高 R，必须把 `_s` 的 G 通道设为对应金属预设或 `255` 泛用金属。
- 玻璃、冰、湿润表面通常提高 R；普通非金属的 G 多数仍保持在 `8-20`。
- `_n` 的 B 是 AO，不是法线 Z；不要直接把常规 normal map 的蓝通道原样当作 LabPBR B 通道。
- `_n` 的 A 是高度；如果不做 POM/视差，保持 `255`。
- `_s` 的 B 在 `0-64` 是孔隙率，在 `65-255` 是 SSS；同一像素不能同时表达两者。
- `_s` 的 A 为自发光强度；不需要发光时用 `0`，需要兼容“忽略自发光”时可用 `255`。
