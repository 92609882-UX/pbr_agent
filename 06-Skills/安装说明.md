# 技能安装说明

本目录下的 `pbr-texture-pipeline.md` 是**给 AI 助手用的技能文件**（Skill）。
装好之后，助手在处理 Minecraft PBR / LabPBR / Substance 3D Designer 相关任务时会自动加载这份知识。

---

## 一、文件格式

技能文件 = **YAML frontmatter** + 正文：

```markdown
---
name: pbr-texture-pipeline
description: Minecraft LabPBR 1.3 材质包全流程权威总纲（Substance 3D Designer 版）—— ……
---

# Minecraft PBR 材质包制作总纲（Substance 3D Designer 流程）

……（正文，与 `01-总纲\PBR材质包制作总纲.md` 的正文一致）
```

- `name` 是技能标识；`description` 决定助手**什么任务会自动加载它**，别删
- 正文与 `01-总纲\PBR材质包制作总纲.md` 的正文一致。两者差别只有两处：
  技能文件**少了** License 协议行和标题下方的「定位 / 同源副本」引用块（那两段是给项目内阅读者看的），
  **多了**开头那段 frontmatter
- 所以：**改知识只需改总纲**，然后按下面的「同步」重新生成技能文件

---

## 二、装到 DeepSeek Harness（DSH）

DSH 会扫描两个技能根目录：

| 根目录 | 用途 |
|---|---|
| `~/.dsh/skills` | DSH 用户技能 |
| `~/.agents/skills` | 跨工具共享技能（Claude Code 等也读） |

**两种布局都被支持**：`<名称>/SKILL.md` 或**平铺的 `<名称>.md`**。推荐平铺，最简单：

```powershell
# DSH 用户技能
Copy-Item ".\pbr-texture-pipeline.md" "$env:USERPROFILE\.dsh\skills\" -Force

# 或：跨工具共享技能
Copy-Item ".\pbr-texture-pipeline.md" "$env:USERPROFILE\.agents\skills\" -Force
```

- 文件名不必是 `SKILL.md`（那个名字只用于子目录布局）
- 技能目录有**文件监听，拷进去即时生效，无需重启**
- 也可以在 DSH 桌面端的「设置 → Skills 与 MCP」里查看是否已加载

## 三、装到 Reasonix

```powershell
Copy-Item ".\pbr-texture-pipeline.md" "$env:USERPROFILE\.reasonix\skills\" -Force
```

## 四、装到其他 AI 助手 / 通用做法

技能格式本质就是「**带 frontmatter 的 Markdown**」，多数支持技能的工具有类似约定。
若不支持，也有两条路：

1. **直接投喂**：把 `01-总纲\PBR材质包制作总纲.md` 的正文粘进对话或系统提示。
   这份文档本来就是为投喂给 Agent 写的——硬约束、精确参数、可执行校验、故障→成因→处置三段式。
2. **作为附件**：把总纲文件挂进对话上下文。

---

## 五、同步（改完总纲之后）

技能文件是总纲的**派生副本**。改完 `01-总纲\PBR材质包制作总纲.md` 后，按下面两步重建：

1. 删掉总纲文件的 **License 协议行** 和标题下方的 **「定位 / 同源副本」引用块**
2. 在文件开头补上带 `name` / `description` 的 YAML frontmatter

然后重新拷贝到各技能目录（**多份技能副本必须保持一致**）。

> 也可以直接让 AI 助手按这句话重新生成：

```
读 01-总纲\PBR材质包制作总纲.md，去掉协议行与定位块，加上 name/description 的 YAML frontmatter，
输出为 pbr-texture-pipeline.md 技能文件，并覆盖到 ~/.dsh/skills/ 与 ~/.reasonix/skills/。
```

## 六、验证是否装好

装完后，问助手一个应当命中它的问题，例如：

```
给 Minecraft 模组方块做 PBR 材质包，_n 贴图的 B 通道是法线 Z 吗？
```

**正确回答**：不是。LabPBR 里 `_n` 的 **B 是材质 AO**（0=全遮蔽，255=无遮蔽），
法线 Z 由 `sqrt(1 - dot(xy,xy))` 重建；`_n` 的 **A 才是高度**。
如果助手答不上来或答错，说明技能没加载成功——检查文件是否放进了上表的根目录。
